# Vaylume 🔐

AI-powered personal vault for secure file storage, smart learning, private notes and everyday productivity, all in one place.

## Features
- Secure signup, login and logout
- Fingerprint and PIN lock (PIN is the fallback)
- Memories and photos vault
- AI Notes explained in the style of your interest
- Documents locker (Aadhaar, marks memos, certificates)
- Multi-language: English, Telugu, Hindi, Gujarati, Marathi, Kannada

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Python, FastAPI
- AI: Google Gemini

## How to Run
1. Clone the repo: `git clone https://github.com/kjahnavi45/vaylume.git`
2. Go to the backend folder: `cd backend`
3. Install dependencies: `pip install -r requirements.txt`
4. Create a `.env` file in `backend` with your key: `GEMINI_API_KEY=your_key`
5. Start the server: `uvicorn main:app --reload`
6. Open the frontend in your browser
